# Admin Updater Extension

Chrome extension для массового обновления объявлений Avito и CIAN с сервера.

## Назначение

Расширение работает как "воркер" — опрачивает сервер на предмет объявлений, требующих обновления, парсит актуальные данные с сайтов и отправляет обновления обратно на сервер.

## Установка

1. Откройте `chrome://extensions`
2. Включите "Режим разработчика"
3. Нажмите "Загрузить распакованное расширение"
4. Выберите папку `dist/`

## Сборка

```bash
cd admin-updater
npm install
bash build.sh
```

## Архитектура

```
popup/
  popup.html      — UI расширения
  popup.ts        — логика popup
  styles.css      — стили

background/
  service-worker.ts — основной сервис-воркер

parsers/
  avito-check.ts   — быстрая проверка Avito (fetch)
  avito-parse.ts   — полный парсинг Avito (chrome.scripting)
  cian-check.ts    — быстрая проверка CIAN (fetch)
  cian-parse.ts    — полный парсинг CIAN (chrome.scripting)

services/
  api-client.ts     — HTTP клиент для сервера
  update-manager.ts — оркестратор обновления

types/
  index.ts          — TypeScript типы
```

## Принцип работы

1. **Получение заданий** — расширение запрашивает у сервера объявления для обновления
2. **Быстрая проверка (CHECK)** — через `fetch` проверяется, изменилась ли цена/статус
3. **Полный парсинг (PARSE)** — если данные изменились, открывается страница и парсится полностью
4. **Отправка обновлений** — результаты отправляются на сервер батчами

## Настройки

- **Источник**: Avito или CIAN
- **Интервал опроса**: 30-300 секунд (по умолчанию 60)
- **Размер батча**: 10-1000 объявлений (по умолчанию 100)

## API сервера

- `GET /api/ads/pending-update` — объявления для обновления
- `GET /api/ads/pending-update/stats` — статистика
- `PUT /api/ads/{id}/update` — обновление объявления
- `POST /api/ads/batch-update` — массовое обновление
