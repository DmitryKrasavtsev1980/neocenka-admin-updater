# Два модема E3372-325 + 4 браузера

Железо: **2× Huawei E3372-325 (stick mode)** + **Baseus BS-HUB001** (питаемый USB 3.0 хаб).

## 1. Железо

```
[USB хаб Baseus BS-HUB001, ВНЕШНЕЕ ПИТАНИЕ ОБЯЗАТЕЛЬНО]
   ├─ E3372-325 #1  → SIM A
   └─ E3372-325 #2  → SIM B
          │
          └── USB в ПК (Windows)
```

1. Включить **внешнее питание хаба** (без него стики не поднимутся).
2. SIM-карты — лучше **двух разных операторов**: флуд-контроль и баны
   не пересекаются, и смена IP у одного не трогает второй.
3. Вставить стики в хаб, дождаться установки драйверов Windows.

## 2. Windows: порты и адаптеры

После подключения в «Диспетчере устройств» появится **два** комплекта:

| Где | Что искать | Зачем |
|---|---|---|
| Сетевые адаптеры | `Huawei Mobile Broadband #1`, `#2` | каналы в интернет (IP1 / IP2) |
| Порты (COM и LPT) | `Huawei Mobile Connect - PC UI Interface` → **COM3**, **COM4** | AT-команды |

Запомни **COM-порт каждого стика** (какой COM у какого — определи по очереди
вынимания, либо просто закрепи: первый всегда A).

Проверка связи (PowerShell):
```powershell
# замени COM3
$sp = [System.IO.Ports.SerialPort]::new('COM3', 115200, 'None', 8, 'One')
$sp.Open(); $sp.Write("AT`r"); Start-Sleep -m 500; $sp.ReadExisting(); $sp.Close()
```
Должно вернуться `OK`. Если пусто — не тот COM или стик ещё поднимается.

## 3. AT-хелперы (смена IP)

Chrome не имеет доступа к COM-портам — смена IP идёт через локальный хелпер.

```powershell
cd C:\Projects\ret\admin-updater\tools\modem-at-helper
npm install

# модем A
node index.js --slot A --com COM3 --port 8891

# модем B (второе окно)
node index.js --slot B --com COM4 --port 8892
```

Проверка:
```
curl http://127.0.0.1:8891/status
curl -X POST http://127.0.0.1:8891/rotate
```
После `/rotate` через 30–40 с оператор выдаёт новый внешний адрес.

## 4. Прокси: 4 браузера через 2 IP

Chrome нельзя прибить к сетевому интерфейсу напрямую — разводим через
прокси, каждый привязан к своему адаптеру.

**3proxy** (лёгкий, бесплатный, portable) — `3proxy.cfg`:

```
# модем A
proxy -p8881 -i127.0.0.1 -e192.168.0.1
# модем B
proxy -p8882 -i127.0.0.1 -e192.168.0.2
```
`-e` — IP, к которому привязан исходящий трафик (свой адаптер).
Свой IP адаптера смотри: `ipconfig` (раздел «Ethernet adapter / Huawei»).

Запуск: `3proxy.exe 3proxy.cfg`

Запуск каждого (свой `--user-data-dir`!):
```

  --user-data-dir="C:\Projects\ret\chrome-debug-updater-A-avito" ^
  --proxy-server=127.0.0.1:8881 ^
  --enable-unsafe-extension-debugging
```

Расширение грузить через CDP `Extensions.loadUnpacked`
(`chrome-extension://…`, путь `C:\Projects\ret\admin-updater\dist`).

## 6. Настройки расширения (в popup каждого профиля)

Модем A:
```
modemMethod: 'at'
modemHost:   'http://127.0.0.1:8891'
modemSlot:   'A'
modemEnabled: true
```

Модем B:
```
modemMethod: 'at'
modemHost:   'http://127.0.0.1:8892'
modemSlot:   'B'
modemEnabled: true
```

Темп (SOURCE_TEMPO) уже зашит в код и **не** переопределяется настройками.

## 7. Схема локов

Сервер держит **отдельный лок на каждый модем** (`ip_rotate:A`, `ip_rotate:B`).
Крутит IP модема A — воркеры на B работают, их лок не касается.

## 9. Частые проблемы

| Симптом | Причина | Что делать |
|---|---|---|
| Стик не виден в Device Manager | хаб без питания | включить внешнее питание Baseus |
| `AT no response` | не тот COM / стик занят | проверить COM в диспетчере, закрыть другие программы |
| IP не меняется после `/rotate` | оператор не перевыдаёт адрес | повторить `AT+CFUN=0` с паузой 15 с, или переткнуть стик |
| 404 в хелпере | хелпер не поднят | `node index.js --slot A --com COM3 --port 8891` |
| Chrome не ходит в сеть | прокси не привязан к своему адаптеру | проверить `-e<ip>` в 3proxy.cfg |
